Область войска Донского — рождения, 1888

1887 → 1888 → 1889
82,284 → 147,277 → 117,336

Здесь 147,277 совершенно определённо должно быть 117,277.

  • население ОВД = 1,962,369;
  • напечатанная рождаемость = 59.7‰;
  • напечатанное число рождений = 147,277.

147,277 даёт совершенно невозможные ~75‰. Но главное — есть независимая арифметическая проверка по итогам таблицы:

  • неземские губернии: 887,317;
  • привислинские и остзейские: 399,713;
  • земские: 3,175,386;
  • вся Европейская Россия: 4,579,693.

Следовательно, ОВД:

4,579,693 − 887,317 − 399,713 − 3,175,386 = 117,277.

То есть тут не нужно ничего интерполировать:

ОВД births 1888: 147,277 → 117,277.

Это заодно почти точно совпадает с 1889 годом: 117,336.

ЦСК "Движение населения Европейской России" (1888:4) даёт 118,122.
